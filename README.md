# Casa de Leilões

## Descrição do projeto
Sistema desenvolvido para gerenciamento de uma casa de leilões, permitindo o cadastro, listagem e venda de produtos por meio de uma interface prática e organizada.

## Funcionalidades
- Cadastro de produtos
- Listagem de produtos cadastrados
- Venda de produtos
- Interface gráfica para interação do usuário
- Gerenciamento básico dos dados dos produtos

## Instalação e utilização

### Pré-requisitos
- Java JDK
- NetBeans
- MySQL

### Como executar o projeto
1. Abra o projeto no NetBeans

2. Configure o banco de dados MySQL

3. Execute o projeto pelo NetBeans
